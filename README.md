# Бот предложки для сообществ ВК

Нужен ключ с привелегия longpollapi на отсылку сообщений с фотографиями и т.п.

```dotenv
# Ключ API!
VK_API_KEY="КлючикОтAPI"
# id беседы в группе 
# https://vk.com/im/convo/2000000003?entrypoint=unknown&rp=peer2000000003
# в этой ссылке id беседы 3,
VK_TALK_ID=3
# Неиспользуется
DELAY=300
```
