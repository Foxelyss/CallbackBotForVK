# Бот предложки для сообществ ВК

Зависимости: python3 и библиотеки указанные в файле requirements.txt

Для работы создайте конфигурацию в файле.env

Нужен ключ с привелегия longpollapi на отсылку сообщений с фотографиями и т.п.

> .env
> ```dotenv
> # Ключ API!
> VK_API_KEY="КлючикОтAPI"
> # id беседы в группе, находится при заходе в беседу через настройки сообщества
> # https://vk.com/gim1234?sel=c1
> # в этой ссылке id беседы 1,
> VK_TALK_ID=1
> # Режим отладки(показ ошибок), если не нужен, удалите переменную окружения или сделайте её пустой
> DEBUG=true
> # Неиспользуется
> DELAY=300
> ```
